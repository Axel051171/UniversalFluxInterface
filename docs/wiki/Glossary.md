# Glossary

**Sprache / Language:** [Deutsch](Glossar) | [English](Glossary)

| Term | Meaning in UFI |
|---|---|
| Flux transition | Magnetic transition appearing as a pulse at the drive output |
| Tick | Timer unit; nominally 1/275,000,000 s for UFI flux data |
| Index | Reference pulse per revolution, or a boundary generated by the selected mode |
| Physical index | Angular reference measured by the drive or a suitable sensor |
| Time slice | Time-based subdivision without a fixed physical angular reference |
| Lead-in | Flux captured before the first index accepted as the start |
| MFM, FM, GCR | Families of magnetic data encodings |
| PLL | Method for reconstructing a cell clock from flux intervals |
| Bit cell | Time interval in the reconstructed encoding clock |
| DMA | Hardware transfer between a peripheral and memory |
| PSRAM | External RAM used for the flux buffer |
| Ring buffer | Memory whose consumed portions can be reused |
| Overcapture | A capture event was not collected in time; at least one event may be missing |
| Underrun | Write output does not receive new data in time |
| WGATE | Drive write-enable signal |
| Precompensation | Deliberate timing adjustment of write transitions |
| Verification | Checks with different evidence levels after writing |
| Fingerprint | Condensed capture characteristics; depending on the method, not proof of identical content |
| Generation | Session-related change counter for configuration, media or capture |
| Provenance | Origin and context information for a capture |
| CRC | Checksum detecting certain data errors |
| SHA-256 | Hash used to compare the same file or dataset |
| CDC | USB class for the serial host connection |
| Composite | USB device exposing several interfaces |
| IEC | Commodore serial drive bus |
| SWD | STM32 debugging and programming interface |
| DFU | USB mechanism for transferring firmware |
